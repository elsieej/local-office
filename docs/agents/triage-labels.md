# Nhãn triage

Các skill nói theo năm vai trò triage chuẩn. File này ánh xạ những vai trò đó sang chuỗi nhãn thực tế mà issue tracker của repo dùng.

| Nhãn trong mattpocock/skills | Nhãn trong tracker của ta | Ý nghĩa                                     |
| ---------------------------- | ------------------------- | ------------------------------------------- |
| `needs-triage`               | `needs-triage`            | Maintainer cần xem xét, phân loại issue này |
| `needs-info`                 | `needs-info`              | Đang chờ người báo cáo bổ sung thông tin    |
| `ready-for-agent`            | `ready-for-agent`         | Đã đặc tả đầy đủ, agent chạy AFK làm được   |
| `ready-for-human`            | `ready-for-human`         | Cần người thật triển khai                   |
| `wontfix`                    | `wontfix`                 | Sẽ không xử lý                              |

Khi một skill nhắc tới một vai trò (ví dụ "apply the AFK-ready triage label"), dùng đúng chuỗi nhãn ở cột tương ứng trong bảng trên.

Sửa cột bên phải cho khớp với bộ từ vựng bạn thực sự dùng.
